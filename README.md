# Froggy Jump 2D (Лягушонок-прыгун)

Красочная и плавная 2D веб-игра в жанре «вертикальный джемпер» (похожая на классический *Doodle Jump*), специально оптимизированная под Android и мобильные браузеры.

## 🌟 Особенности игры

- **Управление на Android:**
  - **Экранные кнопки ◀ ▶:** удобные большие кнопки под пальцы внизу экрана.
  - **Сенсорные свайпы / перетаскивание:** удерживайте палец в любой части экрана, и лягушонок будет следовать за ним.
  - **Гироскоп (акселерометр):** переключатель «Управление наклоном» в меню — поворачивайте телефон влево и вправо для управления персонажем.
  - **Клавиатура (для ПК/тестов):** стрелки влево/вправо, клавиши `A` / `D`, пробел или `P` для паузы.
- **Интерактивные платформы:**
  - 🌿 **Обычная кувшинка:** надежная зеленая опора с цветком лотоса.
  - 💧 **Движущаяся кувшинка:** плавно скользит влево и вправо.
  - 🍂 **Сухой ломкий лист:** трескается и распадается на части при первом же касании.
  - 🍄 **Пружинящий грибок:** взрывной мега-прыжок на огромную высоту!
  - 🔮 **Исчезающий цветок:** периодически тает и появляется вновь.
- **Бонусы и сбор предметов:**
  - 🪰 **Мошки/мушки:** сбор дает +100 очков к высоте и золотые искры.
  - 🪽 **Крылья стрекозы:** режим свободного вертикального полета на 3.5 секунды.
  - 🫧 **Мыльный пузырь-щит:** спасает от одного случайного падения в бездну!
- **Аудиосистема (Web Audio API):**
  - Полностью автономный процедурный звук без внешних файлов: прыжки, суперпрыжки, хруст листьев, звон мошек, финальный аккорд.
  - Кнопка отключения звука (сохраняется в `localStorage`).
- **Сохранение рекордов:**
  - Лучший рекорд и пойманные мушки сохраняются в памяти устройства.
- **PWA-готовность:**
  - Файл `manifest.json` позволяет установить игру прямо на рабочий стол Android как нативное приложение (через меню Chrome «Добавить на главный экран»).

## 🚀 Запуск игры

### Вариант 1: Через локальный Python сервер (рекомендуется)
```bash
python /data/user/0/com.agy/files/.gemini/antigravity-app/scratch/frog-jump-game/server.py
```
После запуска откройте в браузере: `http://127.0.0.1:8080`

### Вариант 2: Прямое открытие файла
Откройте `index.html` в любом современном браузере.

## 📂 Структура проекта
