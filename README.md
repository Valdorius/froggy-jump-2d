# Froggy Jump 2D (Лягушонок-прыгун)

Красочная и плавная 2D веб-игра в жанре «вертикальный джемпер» (в духе классического *Doodle Jump*), полностью адаптированная как для **ПК (клавиатура / мышь)**, так и для **Android и мобильных браузеров (сенсор / гироскоп)**.

## 🎮 Управление в игре

### 💻 На компьютере (ПК / Ноутбук)
- **Стрелочки влево и вправо (🡄 / 🡆):** перемещение лягушонка влево и вправо.
- **Клавиши A / D (или русская раскладка Ф / В):** альтернативное перемещение.
- **Пробел (Space):** пауза и продолжение во время игры, а также быстрый старт / рестарт в меню.
- **Клавиша Enter:** начать игру или играть снова после падения.
- **Клавиша Escape или P:** быстрая пауза.
- **Мышь:** клики по экрану или перетаскивание курсора направляют лягушонка.

### 📱 На смартфонах и планшетах (Android / iOS)
- **Экранные кнопки ◀ ▶:** удобные крупные кнопки внизу экрана.
- **Сенсорные свайпы / перетаскивание:** удерживайте палец в любой точке экрана.
- **Управление наклоном (гироскоп):** переключатель в главном меню позволяет управлять наклоном корпуса устройства.

## 🌿 Интерактивные платформы

- 🌿 **Обычная кувшинка:** стабильная опора с цветком лотоса.
- 💧 **Движущаяся кувшинка:** непрерывно скользит влево-вправо.
- 🍂 **Сухой ломкий лист:** ломается и осыпается при первом касании.
- 🍄 **Пружинящий грибок:** мощнейший взрывной супер-прыжок вверх!
- 🔮 **Исчезающий цветок:** периодически мерцает и исчезает.

## 🪰 Бонусы и усиления

- 🪰 **Мошки/мушки:** +100 бонусных очков к высоте и золотые искры.
- 🪽 **Крылья стрекозы:** 3.5 секунды свободного вертикального полета.
- 🫧 **Мыльный пузырь-щит:** спасает от одного случайного падения в воду!

## 🚀 Запуск игры

- **Онлайн на GitHub Pages:** [https://valdorius.github.io/froggy-jump-2d/](https://valdorius.github.io/froggy-jump-2d/)
- **Локально через Python сервер:**
  ```bash
  python server.py
  ```
  После запуска откройте в браузере: `http://127.0.0.1:8080`
